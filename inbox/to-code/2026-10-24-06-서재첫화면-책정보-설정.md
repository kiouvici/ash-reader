## A. 서재 첫 화면 = B안
1. 위 탭(최근·전체·형식·폴더·시리즈) 없앰. 첫 화면 = 큰 제목 '서재' + 검색 단추 + **2×2 카드: 전체·형식·폴더·시리즈**(각 카드: 이름 18sp 굵게, "312권/6가지/4개/3개", 오른쪽 아래 표지 2장 바닥에 붙어 겹침) + 아래 **'최근 ›' 책장 줄**(읽는 중·최근 연 책·최근 추가, 최근 쓴 순, 진행 막대). '최근 ›' 누르면 최근 전체 격자.
2. 카드 누르면 작업 05 묶음 화면으로 확대 전환. '전체' 카드 = 모든 책 격자(+정렬·검색).
3. **가로 화면**(LibraryHomeLand): 네 카드 한 줄 + 최근 책장. 태블릿 가로 카드 높이 210dp·표지 96dp, 최근 표지 152dp 10권 보임. 휴대폰 가로 카드 96dp·표지 52dp, 최근 표지 80dp. 가로에서는 아래 내비게이션을 위 제목 줄 오른쪽 막대로 옮김(세로 공간 확보). 태블릿 세로는 휴대폰 세로 배치를 크게.

## B. 책 정보(지은이·출판사·표지) — 대표님 우선순위
1. **1순위 파일 정보**(정확도 높음일 때만): EPUB·MOBI·AZW3·FB2 의 제목·지은이·표지(표지로 표시된 그림), 글자 있는 PDF 의 Title/Author. **믿지 않는 값**: 'Administrator'·'user'·'Microsoft Word - …'·PC 이름·빈 값·파일 이름과 같은 Title 등 → 2순위로.
2. **2순위 인터넷 자동 매칭**: 대상 = 스캔 PDF·DjVu·만화(CBZ/CBR/CB7)·정보 없는/틀린 이북. **한글·Word 는 자동 검색 제외**(책 정보 화면에서 직접 찾기는 됨). 검색어 = 파일 이름 정리([출판사]·(완)·v1.2·스캔·해상도 등 지우고 권수 따로). **자동 적용은 일치도 90% 이상 + 권수 일치일 때만**, 아니면 바꾸지 않고 '확인 필요' 작은 표시.
3. **3순위 직접 고르기**(BookInfo 목업): 표지 길게 누름 → 책 정보(칸마다 출처 표시: 파일/파일 이름/인터넷/직접) · 표지 고르기[인터넷 / 첫 쪽 / 파일 속 그림 / 사진에서] · [다른 정보 찾기] → 검색어 고쳐 다시 찾기, 결과 일치도 순, 누르면 적용 · [원래대로].
4. 시리즈: 한 권을 직접 고르면 "나머지 권도 같은 책으로 맞출까요?".
5. **출처**: 국립중앙도서관(서지 API) + 알라딘(Open API) + 구글 북스. **API 키는 저장소에 넣지 않는다** — 노트북 `local.properties`(커밋 금지)·GitHub Secrets 에서 빌드 때 BuildConfig 로. 키 발급은 대표님(대화창이 안내) — 키 없으면 구글 북스만으로 동작.
6. 받은 표지는 앱 저장소에 보관(다음부터 오프라인), 서재 정보만 바꾸고 **파일은 절대 고치지 않음**. 백업(.ashbak)에 책 정보·고른 표지 포함.
7. DB: Room 6→7 이주 — author, publisher, isbn, coverSource(file/firstPage/internet/user/photo), metaSource, matchScore, needsReview 등. `app/schemas` + `AshDbMigrationTest`.
