## A. 전체 책 격자 (LibraryAll)
1. 3열(휴대폰 세로), 태블릿은 폭에 맞춰 늘림. 표지 바닥선 맞춤, 표지 아래 한 줄 = [새 책 알약 / 진행 %] + 오른쪽 ⋯ 단추.
2. 이북·만화는 **제목 없이 표지만**, 문서(HWP·HWPX·PDF·DOCX)는 표지 아래 제목 1줄.
3. 시리즈는 표지 겹쳐 쌓기 + "N권의 책". 맨 아래 "312권의 책" 개수.

## B. 서재 메뉴 (LibraryMenus)
1. **≡ 모음**(오른쪽 위): 전체·형식·폴더·시리즈·읽는 중·다 읽음·최근 받은 파일·숨긴 책 + 권수 + ›, 아래 '새 모음…', 위 '편집'(순서 바꾸기·숨기기). 새 모음 = 사용자가 고른 책 묶음(Room 테이블 추가, 백업 포함).
2. **⋯ 보기·정렬**: 선택 / 격자·목록 / 정렬(최근 읽은 순·제목·지은이·추가한 날·직접 정렬). 묶음마다 기억.
3. **목록 보기**: 큰 표지 92dp + 제목 17sp + 지은이 + 상태(파란 굵게) + 첫 문단 3줄 + [이어 읽기] + ⋯. 만화는 첫 문단 대신 시리즈·권수.
4. **서재 검색**: '제목' 가로 표지 줄 + '본문 N권에서 N곳'(책·문장·쪽수, 검색어 노란 칠) + 폴더·형식·시리즈 이름도 찾기. 본문 검색은 기존 색인 쓰고, 없으면 제목만.

## C. 묶음 안 화면 (SeriesDetail)
- 위 색 머리(표지 대표색 그라데이션) + 펼친 표지 5장 + 이름·지은이·"시리즈 · 24권 · 만화" + [이어 읽기 / 책 이름 · %] 단추 + 아래 책 목록(작은 표지·제목·지은이·상태·⋯).
- **시리즈·폴더·형식 모두 같은 머리**(목업 ③ 폴더 예). 폴더는 경로 표시, 목록↔격자 바꾸기.

## D. 책 ⋯ 메뉴 (MoreMenu)
- ⋯ 누름 또는 표지 길게 누름 → 유리 메뉴: 위 아이콘 3개[공유·책 정보·파일 위치] / 시리즈로 묶기·다 읽음으로 표시·표지 바꾸기·처음부터 다시 읽기 / 구분선 / 서재에서 숨기기·**서재에서 빼기…(빨강, 확인 창)**. '빼기'는 서재 목록에서만 — **파일은 지우지 않음**(문구로 명시).

## E. 읽기 화면 새 디자인 (ReaderNew)
1. 평소엔 쪽수만. 한 번 누르면: 위 "챕터 끝까지 N쪽 남음" + ✕ / 아래 가운데 "4 / 67" / 왼쪽 아래 안내선 단추 / 오른쪽 아래 메뉴 단추.
2. 메뉴 단추 → 떠 있는 메뉴 쌓기(오른쪽 아래): [목차 · 4%] [책 검색] [테마 및 설정 가가] [공유 · 안내선 · 책갈피]. 기존 위·아래 막대 메뉴를 이걸로 바꿈. 기존 기능은 빠짐없이 이 안으로(못 들어가는 것은 '테마 및 설정 › 사용자화' 안).
3. **테마 및 설정** 시트: 가/가 크기 · 쪽 넘김/스크롤 · 어둡게 · 밝기 막대 · 테마 6개 타일(원본·고요·종이·볼드·평온·집중, 고른 것 파란 테두리) · [사용자화(글꼴·줄 간격·여백·넘김 효과)]. **AI 화질 향상은 작업 04에서 정한 자리 그대로** 이 시트 안에 유지(이북·PDF·만화 같은 자리).
4. **책 검색** 시트: '이 책에서 N곳', 장·쪽 + 문장(검색어 칠), 누르면 이동, 찾은 곳 ‹ › 이동.
5. **안내선**: 한 줄 띠만 밝게(노란 옅은 칠), 나머지 흐리게, 위아래 끌기, 두 번 누르면 끔. 스크롤 보기에서도 동작.
6. 만화·HWP·Word 도 같은 바깥 틀(위·아래·메뉴) 사용.
