## 할 일
1. **서재 위 탭**(최근·전체·형식·폴더·시리즈): 화면 위 가운데 떠 있는 반투명 막대. 모서리 11dp(안쪽 선택 칸 8dp — 대표님 "알약이어도 모서리 줄여"), 고른 탭 = 옅은 회색 칸 + 굵게. 아래 내비게이션(서재·독서 기록·설정)도 같은 모양(모서리 13/10dp).
2. **형식·폴더·시리즈 첫 화면 = 묶음 카드 목록**
   - 큰 제목(형식/폴더/시리즈, 30sp 굵게), 바탕 위 흰색→아래 #F1F1F3.
   - 카드: 흰색, 모서리 12dp, 높이 116dp, 옅은 그림자. 왼쪽 = 이름(17sp 굵게) + "폴더 2개  64권"(13sp 회색). 오른쪽 = 그 묶음 책 표지 3장이 **카드 바닥에 붙어 서서 겹침**(높이 조금씩 다르게, 오른쪽 끝은 카드 밖으로 잘림).
   - 폴더별은 서재 폴더(맨 위 단계)만 카드. 하위 폴더는 안으로 들어가서 보임.
3. **카드를 누르면 '폴더 안으로 들어가기' 전환**: 누른 카드 자리에서 화면이 커지며 펼쳐짐(약 0.45초), 뒤 목록은 0.94배·흐려짐. 뒤로 = 거꾸로 카드 자리로 줄어듦. 하위 폴더로 한 단계 더 들어갈 때도 같은 방식. '동작 줄이기' 켜져 있으면 바로 바뀜. (Compose: SharedTransitionLayout/sharedBounds 권장)
4. **묶음 안 화면**(애플 북스 '논픽션' 카테고리 화면 구조)
   - 위: 왼쪽 뒤로 단추(44dp, 모서리 12dp, 반투명), 오른쪽 [검색 | 최근 읽은 순] 묶음 단추.
   - 큰 이름(30sp) + "폴더 2개, 책 64권".
   - **책장 줄**: '이어 읽기'(이 묶음에서 읽는 중인 책) → 하위 폴더마다 한 줄("2025 40권 ›"). 줄마다 흰색→#F0F0F2 띠 배경, 표지는 옆으로 넘김(가로 스크롤). › 줄 제목을 누르면 그 하위 폴더 안으로.
   - **모든 책**: 3열 격자(태블릿 가로는 5~6열). 표지 아래끝 맞춤 → 제목 1줄 굵게(말줄임) → 지은이·형식 회색 → 상태 칸(테두리 모서리 6dp: '42%' 파랑 / '새 책' / '다 읽음' / '어제 받음').
   - 정렬(최근 읽은 순·이름·추가한 날)과 묶음 안 검색.
5. **표지 그리기**
   - 실제 표지 사용: 이북 = 책 속 표지, PDF·한글·Word = 첫 쪽 축소, 만화 = 첫 쪽(지금 서재와 같음).
   - 모든 표지: 모서리 1/3dp(책등 쪽 작게), 왼쪽 5dp 책등 접힘 빛(흰→어두움), 아래 그림자(0 12 16 -10, 45%). 천 무늬 없음.
   - **표지 없는 이북** = 애플 북스 기본 표지 방식: 위 밝고 아래 진한 단색 세로 그러데이션(제목으로 색 하나 고정), 안쪽 가는 테두리, 제목 위 가운데(최대 3줄), 지은이 아래 가운데.
