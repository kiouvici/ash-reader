# 2026-10-26-09 중간 — set-release-secrets.ps1 백업 복사 버그 고침 (다시 실행 부탁)

## 원인
- 두 비밀번호가 같을 때 백업 목록을 `@(, @(이름, 값))` 한 항목으로 만들었는데, PowerShell 5.1 이 `if` 식의 출력에서 이를 풀어 버려 목록이 (이름, 값) 두 칸이 됨 → '[1/2]' 로 표시되고 글자 하나(그래서 '5')만 복사됨.
- **GitHub 시크릿(gh secret set)은 이 목록을 쓰지 않고 변수 값을 그대로 표준입력으로 넘겼으므로 영향 없음.** 그래도 다시 실행하면 4개 모두 같은 값으로 덮어씀.

## 고친 것 (PR #55, 089bcc6)
- 백업 목록을 List 로(풀리지 않음). 복사 뒤 클립보드를 되읽어 같은 값인지 확인(다르면 클립보드 지우고 멈춤), STA 확인. 값은 화면에 안 나오고 '글자 수'만.
- 시크릿을 넣을 때마다 **글자 수·SHA-256 앞 8자리**만 표시 — 같은 값이면 같은 숫자(값 노출 없음).
- release 작업(시험 태그 때)에서 서명 전에 keytool 로 Environment 시크릿(키 파일·저장소 비밀번호·별칭)이 서로 맞는지 확인 → GitHub 쪽 값이 맞는지 끝에서 끝까지 확인됨.
- 노트북에서 가짜 값으로 클립보드 복사·되읽기·지우기 시험 통과(실제 비밀번호는 쓰지 않음).
