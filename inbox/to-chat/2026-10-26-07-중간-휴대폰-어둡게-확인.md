# 2026-10-26 작업 07 중간 보고 — 휴대폰 어둡게 실기기 확인

## 요약
- 대표님 허락으로 휴대폰(SM-S948N)에서 앱 테마 '어둡게'로 서재·전체·모음 메뉴·책 ⋯ 메뉴·묶음 안·독서 기록·설정·읽기 화면·테마 및 설정 시트를 찍어 확인. 문제 2개 찾아 고침.
- 확인 뒤 앱 테마는 원래 값('시스템')으로 되돌림.

## 고친 것 (커밋 9408dce, PR #51)
1. 메뉴 뒤 글자가 비쳐 읽기 어려움: 이 휴대폰은 기기 창 흐림이 꺼져 있음(dumpsys mBlurEnabled=false) → 흐림 없이 83% 투명 바탕만 남았음. 기기 창 흐림을 실제로 확인해, 못 흐리면 메뉴·시트 바탕을 불투명 92%로(감수 3 기준). 켜고 끄면 바로 따라감. 아래 내비게이션 막대(일부러 비치게)는 그대로.
2. 앱 테마 어둡게 + 밝은 종이로 읽을 때 상태 표시줄 아이콘이 흰색이라 시계가 안 보임: 앱 테마가 다시 그려질 때 읽기 화면 값을 덮어썼음 → 아이콘 색을 한 곳에서 정하도록(읽는 동안 종이 색, 나가면 앱 테마). 실기기 확인 완료.

## 이상 없음
- 서재 첫 화면·전체 격자·묶음 머리·독서 기록·설정·책 정보 색: 어둡게 색 적용 정상.

## 남은 문제·제안
- 읽기 화면 위 "N% 읽음/챕터 마지막 쪽" 글자가 본문 첫 줄과 겹쳐 보임(TXT·HWP). 어둡게와 상관없는 배치 문제 — 고칠지 결정 필요(화면 변경).
- 독서 기록: '이번 주 0분'인데 월요일 막대가 가득 참(1분 미만을 0분으로 표시하면서 막대는 최대 높이). 제안만.
- 태블릿 스크린샷은 태블릿 연결 뒤. 화면 사진은 대표님 개인 문서가 보여 저장소·Releases 에 올리지 않음.
- 확인 중 개인 문서 하나(공문)를 열어 '최근' 목록 순서가 바뀜.
