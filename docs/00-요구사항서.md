## 1. 목적

이북 파일과 업무 문서(HWP·HWPX·Word)를 앱 하나로 바로 열어 읽는 안드로이드 이북 리더.
급하게 받은 파일을 다른 앱 설치 없이 이 앱에서 바로 읽는 것이 핵심 목표다.

## 2. 사용 환경

| 항목 | 내용 |
|---|---|
| 기기 | 안드로이드 휴대폰, 안드로이드 태블릿 (태블릿 = 짧은 변 600dp 이상) |
| 최소 버전 | Android 8.0 (API 26) 이상 |
| 기준 기기 | 휴대폰: 갤럭시 A35급 / 태블릿: 갤럭시 탭 S9 FE급 / 최저: Android 8 기기 1대 |
| 화면 | 세로·가로 모두 지원. 태블릿 가로 모드는 두 쪽 펼침 보기 |
| 네트워크 | 불필요 (완전 오프라인, INTERNET 권한 없음) |
| 광고·계정·서버 | 없음 |
| 배포 | GitHub Actions로 APK 빌드, 직접 설치(사이드로드). 업데이트는 새 APK 덮어 설치 |
| 서명 | 릴리스 서명 키는 GitHub Secrets에 보관하고 별도 백업. versionCode 자동 증가 |
| 배포 정책 | 구글 사이드로드 개발자 인증 정책은 7단계 배포 전에 다시 확인 |

## 3. 지원 형식

아래 표가 지원 형식의 전부다.

| 구분 | 형식 | 범위 |
|---|---|---|
| 이북 | EPUB(2·3), MOBI, AZW3, FB2, TXT, RTF, HTML, CHM | DRM 없는 파일만 |
| 문서 | PDF, DjVu | 지원 (D-001 A안) |
| 만화 | CBZ, CBR | CBR은 RAR4·RAR5 모두 |
| 한글 | HWP 5.0, HWPX | 일반·배포용 문서 열람. 암호 문서는 암호 입력 후 열람(가능 시). HWP 3.0/97 제외(안내 표시) |
| MS 오피스 | DOCX, DOC | Word만. DOCX는 구조 보존 보기, DOC는 본문·표 텍스트 보기 |
| 압축 | ZIP | 안에 든 지원 형식 파일을 바로 열기 |

## 4. 기능 요구사항

형식별 적용 범위는 부록 A, 형식과 무관한 공통 기능은 부록 B를 따른다. QA는 부록 A·B로만 판정한다.

### 4.1 서재
- F-01 저장소 접근
  - Android 11 이상: '모든 파일 접근' 권한을 요청한다(사이드로드 배포라 Play 정책 대상 아님). 거부하면 폴더 선택(SAF, 하위 폴더 단위)으로 대체한다.
  - Android 8~10: 저장소 읽기 권한을 쓴다. Android 10은 requestLegacyExternalStorage=true로 기존 방식을 유지한다.
  - '모든 파일 접근'은 시스템 설정 화면으로 이동해 허용받으며, 그 전에 이유를 설명하는 안내 화면을 둔다.
  - 기본 수집 폴더는 Download와 그 하위 폴더. 사용자가 폴더를 추가·제외할 수 있다.
- F-02 최근 읽은 문서, 전체, 형식별, 폴더별 보기
- F-03 목록 보기 / 표지 보기 전환, 이름·최근·형식 정렬, 파일명 검색
- F-04 문서별 읽은 진행률 표시

### 4.2 외부에서 열기
- F-05 '열기'(ACTION_VIEW)와 '공유하기'(ACTION_SEND)를 모두 받는다. 형식 정보가 없거나 application/octet-stream으로 들어오면 파일 시그니처로 형식을 판별한다. HWP 계열 MIME(application/x-hwp, application/haansofthwp, application/vnd.hancom.hwp, application/hwp+zip 등)을 등록한다.
  - 모든 경로(서재·외부 열기)에서 파일 시그니처를 먼저 보고, 확장자·MIME과 다르면 시그니처 기준 형식으로 연다. 서재에는 실제 형식을 표시한다.
- F-06 외부에서 연 파일은 기본으로 '한 번만 보기'로 연다. 위치를 기억하지 않고, 캐시 사본은 닫을 때 지운다.
  - '서재에 추가'를 누르면 앱 전용 폴더에 사본을 만들어 서재에 넣고, 이어 읽기·책갈피는 이 사본 기준으로 한다. 원본은 건드리지 않는다.
  - 외부에서 연 파일의 식별값(F-63)이 서재 문서와 같으면 서재 기록으로 이어 읽는다.

### 4.3 읽기 화면
- F-07 화면 가운데 탭으로 메뉴 표시/숨김, 기본은 전체 화면
- F-08 쪽 이동: 화면 좌우 가장자리 탭, 스와이프, 볼륨 키
  - 볼륨 키 쪽 넘김은 설정에서 켜고 끌 수 있다. TTS 재생 중에는 볼륨 키를 음량 조절로 쓴다.
  - 확대 상태에서는 스와이프로 화면을 이동하고, 쪽 넘김은 가장자리 탭이나 볼륨 키로만 한다.
- F-09 쪽 이동 슬라이더, 현재 쪽/전체 쪽, 진행률 표시
- F-10 목차, 책갈피, 본문 검색
- F-11 형광펜·메모, 모아보기. 책갈피·형광펜·메모는 앱 내부 DB에만 저장하고 원본 파일에는 쓰지 않는다.
- F-12 텍스트 선택 후 복사·공유
- F-13 TTS: 기기에 설치된 TTS 엔진을 쓴다. 시작·정지·속도, 읽는 위치 표시. 한국어 음성이 없으면 설정 화면으로 안내한다. 화면이 꺼진 뒤에는 미디어 알림과 포그라운드 서비스로 계속 읽는다(Android 13+ 알림 권한 요청, Android 14+ FOREGROUND_SERVICE_MEDIA_PLAYBACK 선언).
- F-14 마지막 읽은 위치 자동 저장, 다시 열면 그 위치에서 시작

### 4.4 페이지 넘김 효과
- F-15 기본: 종이책 넘김 효과(손가락을 따라 종이가 말려 넘어감, 말린 뒷면 표시, 그림자)
- F-16 선택: 슬라이드, 효과 없음
- F-17 쪽 넘김 보기의 모든 형식에 같은 효과를 적용한다(PDF·HWP 원본·만화 등 고정 쪽 문서 포함). 스크롤 보기에서는 넘김 효과를 쓰지 않는다.
- F-18 태블릿 가로 두 쪽 펼침에서도 책 넘김 효과 동작

### 4.5 보기 설정 (이북식 보기)
- F-19 글자 크기, 줄 간격, 문단 간격, 여백, 정렬
- F-20 글꼴 선택(내장 글꼴 + 사용자 글꼴 파일 추가)
- F-21 테마: 주간, 야간, 세피아 + 밝기 조절. 고정 쪽 문서의 야간 모드는 색 반전(그림 제외 옵션)
- F-22 쪽 넘김 / 스크롤 보기 전환

### 4.6 고정 쪽 문서 (PDF·DjVu·HWP 원본 보기·DOCX 구조 보존 보기)
- F-23 확대·축소(두 손가락), 폭 맞춤·쪽 맞춤
- F-24 여백 자르기
- F-25 이북식 보기 전환 버튼: 본문을 뽑아 글자 크기 조절 가능한 이북 화면으로 표시 (HWP·HWPX·DOCX·글자 있는 PDF)

### 4.7 한글(HWP·HWPX)
- F-26 원본 보기: 표·이미지·도형·수식을 원본 쪽 모양대로 표시
  - 합격 기준: 시험 파일에서 문단·표·그림이 한컴오피스 PDF 출력과 육안 대조로 일치하고, 쪽 수 차이 ±1 이내
- F-27 이북식 보기: 본문 문단과 표 내용을 차례대로 표시
- F-28 원본 보기 실패(파싱 오류, 10초 초과, 또는 첫 쪽이 비어 있으면서 문서 본문 텍스트는 있는 경우) 시 이북식 보기로 자동 전환하고 안내
- F-29 내장 글꼴은 OFL 글꼴(나눔·Noto CJK 등)만 쓴다. 한컴 글꼴이 없으면 대체 글꼴로 자동 대응한다. 한컴 글꼴은 재배포 허용이 확인된 경우에만 넣는다.

### 4.8 Word
- F-30 DOCX: 구조 보존 보기(문단·표·그림·머리글/바닥글) + 이북식 보기
  - 구조 보존 보기는 화면 크기에 맞춰 쪽을 다시 나누며, Word와 쪽 수가 같을 필요는 없다.
  - 합격 기준: 시험 파일의 문단 순서·표 칸 구조·그림·머리글/바닥글이 Word PDF 출력과 육안 대조로 빠짐없이 일치
- F-31 DOC(구형): 본문 텍스트와 표 텍스트 보기

### 4.9 TXT
- F-32 한글 인코딩(UTF-8, EUC-KR/CP949, UTF-16) 자동 인식, 수동 변경 가능
- F-33 장·절 제목 자동 인식해 목차 생성

### 4.10 서점 앱 바로가기
- F-36 서재 화면에 '내 서점 앱' 바로가기 줄을 둔다. 기본 항목은 예스24 eBook 앱이며, 사용자가 기기에 설치된 다른 서점 앱(리디·밀리의 서재·교보 등)을 골라 추가·삭제·순서 변경할 수 있다.
  - 누르면 해당 앱을 바로 실행한다. 앱이 설치되어 있지 않으면 안내하고, 사용자가 원하면 Play 스토어 해당 앱 화면을 연다.
  - 서점 앱의 책 목록·파일에는 접근하지 않는다(DRM 도서는 각 서점 앱에서 읽는다).
  - 앱 고르기는 런처 앱(MAIN/LAUNCHER) 조회로 한다(QUERY_ALL_PACKAGES는 쓰지 않는다). 예스24 등 기본 항목은 패키지명을 `<queries>`에 선언하고, ACTION_PROCESS_TEXT(F-66)도 같은 방식으로 선언한다. Play 스토어가 없는 기기에서는 안내만 한다.

### 4.11 소설 읽기 최적화
- F-37 한국어 본문은 띄어쓰기 단위로 줄을 바꾸고, 줄보다 긴 단어(URL 등)만 글자 단위로 끊는다. 설정에서 '글자 단위'로 바꿀 수 있다.
- F-38 마침표·쉼표·닫는 괄호·닫는 따옴표는 줄 첫머리에, 여는 괄호·여는 따옴표는 줄 끝에 오지 않게 한다.
- F-39 하이픈 넣기는 영문 단어에만 쓰고 한국어에는 쓰지 않는다. 기본값은 끔.
- F-40 문단 첫 줄 들여쓰기: 원본 유지 / 1글자 / 2글자 / 없음. 따옴표("「『)로 시작하는 대화문 문단은 들여쓰기를 따로 정한다(같게 / 없음).
- F-41 TXT 정리(원본은 그대로, 화면에만 적용): ① 연속 빈 줄을 하나로 줄이거나 모두 없앰 ② 줄이 . ? ! … " ” 」 』로 끝나지 않고 다음 줄이 빈 줄이 아니면 두 줄을 합침 ③ 줄 앞 공백·전각 공백·탭 제거 후 앱 들여쓰기 적용. 각각 켜고 끌 수 있다.
- F-42 색온도 필터: 따뜻한 색 덧씌우기 강도 조절, 지정 시각 자동 켜기.
- F-43 사용자 색 테마: 글자색·배경색을 직접 정해 저장.
- F-44 자동 넘김(몇 초마다)과 자동 스크롤(속도 조절). 화면 탭으로 일시정지·재개.
- F-45 하단 정보줄: 시계·배터리·이번 장 남은 쪽·전체 진행률·남은 읽기 시간(최근 읽기 속도로 계산). 항목별 켜고 끄기, 위/아래 위치 선택.
- F-46 EPUB 각주 링크를 누르면 팝업으로 보여 주고 읽던 쪽은 유지한다.
- F-47 TTS 잠자기 타이머: 15/30/60분, 장 끝까지.

### 4.12 만화 읽기 최적화
- F-48 넘김 방향(왼→오 / 오→왼 / 위→아래)을 고르고 책마다 기억한다. 책 넘김 효과와 두 쪽 배치도 방향을 따른다. '위→아래'는 세로 연속 스크롤(F-53 웹툰 보기)과 같으며, 책 넘김 효과와 두 쪽 펼침은 쓰지 않는다. 종이책 넘김 효과는 왼→오와 오→왼 방향에만 적용한다.
- F-49 CBZ의 ComicInfo.xml(Manga=YesAndRightToLeft)이나 EPUB의 page-progression-direction=rtl이 있으면 방향을 자동으로 정한다.
- F-50 두 쪽 펼침에서 첫 쪽(표지)은 단독으로 보이고, 짝을 한 쪽 밀거나 되돌리는 버튼을 둔다.
- F-51 가로가 세로보다 긴 쪽은 펼침 그림으로 보고, 두 쪽 모드에서는 단독으로 크게, 한 쪽 모드에서는 '반으로 나눔 / 회전 / 그대로' 중 설정대로 보인다. 나눌 때는 넘김 방향을 따른다.
- F-52 흰·검은 테두리를 자동 감지해 자른다. 펼침 그림은 양쪽을 같은 폭으로 자른다.
- F-53 세로 연속 스크롤(웹툰) 보기: 이미지 사이 간격(0/작게), 좌우 여백, 폭 맞춤 기본. 처음 10장 중 6장 이상이 세로/가로 비율 3 이상이면 처음 열 때 웹툰 보기를 제안한다.
  - 한 변이 4096px을 넘는 이미지는 타일 단위(BitmapRegionDecoder 등)로 보이는 영역만 디코딩한다.
- F-54 맞춤 방식: 화면/폭/높이/원본. 폭 맞춤 시 시작 위치는 읽기 방향에 따라 오른쪽 위 또는 왼쪽 위.
- F-55 두 번 탭하면 2배 확대, 다시 두 번 탭하면 맞춤 상태로 복귀.
- F-56 확대·축소 보간 방식(빠름/고품질)과 선명하게 하기 강도 선택.
- F-57 밝기·대비·감마 조절, 흑백 보기, 색 반전. 책마다 기억.
- F-58 넘김 방향으로 2쪽, 반대 방향으로 1쪽을 미리 해석해 두고(두 쪽 펼침에서는 앞 2펼침·뒤 1펼침), 메모리 상한(기기 RAM의 1/8)을 넘으면 먼 쪽부터 버린다.
- F-59 쪽을 길게 누르면 '서재 표지로 지정 / 이미지 공유'.
- F-60 슬라이더를 끄는 동안 해당 쪽 축소 그림을 띄우고, 만화는 쪽 목록 그리드를 둔다.
- F-72 칸 단위 보기: 기기 안에서(오프라인) 쪽의 칸을 자동 인식한다. 두 방식을 모두 둔다.
  - 눌러서 확대(기본): 쪽 전체를 보다가 칸을 누르면 그 칸이 화면에 맞게 확대되고, 확대된 칸을 다시 누르면 쪽 전체로 돌아온다. 확대 상태에서 넘기면 다음 칸으로 이어진다.
  - 자동 순서: 설정에서 켜면 쪽을 열 때 첫 칸부터 확대해 보여 주고, 넘길 때마다 다음 칸, 마지막 칸 다음에는 다음 쪽 첫 칸으로 이동한다.
  - 칸 순서는 넘김 방향(F-48)을 따른다. 두 번 탭 확대(F-55)와 겹치지 않게, 칸 누르기는 한 번 탭으로 하고 칸 단위 보기가 켜진 경우에만 동작한다. 칸 밖(여백)을 누르면 기존 탭 영역(F-64) 동작을 따른다.
  - 칸 인식 결과는 책마다 저장해 다시 열 때 재계산하지 않는다.
  - 칸을 인식하지 못한 쪽은 쪽 전체 보기로 보여 준다.
  - 칸 단위 보기는 한 쪽 보기로만 동작하고, 칸 사이 이동은 확대 이동 애니메이션으로 한다. 쪽이 바뀔 때만 F-15 넘김 효과를 쓴다.
  - 합격 기준: QA가 시험 만화 3권(왼→오 1권, 오→왼 1권, 컬러 1권) 각 20쪽의 정답 칸 상자를 미리 표시한다. 인식 상자가 정답과 IoU 0.7 이상이면 맞은 칸, 읽기 순서가 틀린 칸은 틀린 칸으로 센다. 인식률(맞은 칸 ÷ 정답 칸) 80% 이상, 쪽당 인식 1초 이내(기준 휴대폰).
- F-73 AI 화질 향상: 기기 안 AI 모델(오프라인)로 저해상도 만화·스캔 쪽을 2배 선명하게 키운다. 쪽의 짧은 변이 화면 짧은 변(px)보다 작은 경우에만 처리하고, 그 외 쪽은 건너뛴다.
  - 기본값은 끔. 책마다 켜고 끄며, 켜면 앞쪽부터 미리 처리해 결과를 캐시(상한 설정, 기본 1GB)에 둔다. 처리되지 않은 쪽은 원본으로 먼저 보여 주고 처리되면 바꿔 끼운다.
  - 기기 성능(GPU·메모리)이 부족하면 기능을 숨기고 이유를 안내한다. 처리 중 발열·배터리 상태를 보고 자동으로 멈출 수 있다.
  - N-02(쪽 이동 1초)는 원본 표시 기준으로 판정하고, 화질 향상 결과는 제외한다.
  - 캐시는 앱 캐시 폴더에 두며 시스템이 지워도 다시 만든다. 문서를 닫아도 지우지 않고(N-09 예외), 백업(F-70)에는 넣지 않는다. 설정에 캐시 지우기 버튼을 둔다.
  - 부록 A의 ●는 기준 휴대폰·태블릿에만 적용하고, 최저 기기는 숨김 안내로 합격으로 본다.
  - 합격 기준: 시험용 저해상도 만화에서 원본 대비 계단 현상·글자 번짐이 눈에 띄게 줄어들고(대표님 육안 확인), 기준 휴대폰에서 쪽당 처리 5초 이내.

### 4.13 공통 편의
- F-61 서재에 있는 문서에서 마지막 쪽을 넘기면 '다음 권 열기' 확인창을 띄우고, 같은 폴더의 다음 권(파일명 숫자 순서: 1, 2, 10)을 연다.
- F-62 같은 폴더 안에서 파일명의 숫자·권·화 표기를 뺀 나머지가 같은 파일이 2개 이상이면 시리즈로 묶어 표지 한 장으로 보이고, 안에서 권별 진행률을 표시한다. 사용자가 묶기를 풀거나 직접 묶을 수 있다.
- F-63 문서는 파일 내용 해시(앞·가운데·뒤 일부와 크기)로 식별해, 이동·이름 변경 후에도 진행·책갈피·형광펜이 이어진다.
- F-64 탭 영역 배치: 좌우 / L자 / 화면 어디든 다음 쪽 / 사용자 지정. 처음 열 때 영역 안내를 잠깐 보여 준다. 왼손잡이용 좌우 반전.
- F-65 화면 왼쪽 가장자리를 위아래로 밀면 앱 밝기 조절(켜고 끌 수 있음). 이 영역은 시스템 제스처 제외 영역(최대 200dp) 안에 두고, 제스처 내비게이션의 뒤로 가기와 겹치지 않아야 한다.
- F-66 텍스트 선택 메뉴에 '사전'을 두고, 기본으로 **말글사전**(대표님 제작 성인용 사전, 패키지 kr.vici.malgeul, ACTION_PROCESS_TEXT 지원)으로 단어를 넘긴다. kr.vici.malgeul을 `<queries>`에 선언한다. 말글사전이 설치되어 있지 않으면 '말글사전 APK를 설치하세요' 안내만 하고 다른 사전 앱(ACTION_PROCESS_TEXT 지원) 선택 화면을 연다. 앱 안 사전·온라인 사전은 두지 않는다.
- F-67 읽기 중 화면 꺼짐 시간(시스템 따름 / 5분 / 계속 켜짐), 메뉴에 회전 잠금 버튼.
- F-68 독서 통계: 책별 누적 시간, 일·주·월 읽은 시간. 앱 내부 DB에만 기록.
- F-69 형광펜·메모를 .txt/.md 파일로 저장하거나 공유.
- F-70 로컬 백업·복원: 진행·책갈피·형광펜·설정을 백업 파일 하나로 내보내고 가져온다(클라우드 백업 차단 보완).
- F-71 문서 상태: 읽을 책 / 읽는 중 / 다 읽음 / 즐겨찾기. 서재에서 거르기.

### 4.14 암호·손상 파일
- F-34 암호 PDF·HWP·DOCX는 암호 입력창을 띄운다. 입력한 암호는 저장하지 않는다.
- F-35 손상·지원 불가 파일은 앱이 종료되지 않고 원인을 알기 쉬운 문구로 안내한다.

## 7. 완료 기준

1. 시험 파일 세트: 형식별 최소 5종(정상·대용량·한글 파일명·손상·암호(해당 형식))을 두고 목록을 `docs/시험파일목록.md`로 관리한다. 1단계 종료 전 QA가 만든다.
   - `test-files/public/`: QA가 만든 파일. 저장소에 포함하고 CI에서 쓴다. DOC 바이너리 시험 파일은 QA가 Word 97-2003 형식으로 따로 만든다.
   - `test-files/private/`: 대표님 실무 파일 5종(HWPX·HWP·DOC·DOCX·PDF, 수령 완료). .gitignore로 저장소에 올리지 않고 로컬 QA 전용으로 쓴다. 이 중 .doc 파일은 실제로는 RTF라 시그니처 판별(F-05) 시험에 쓴다.
2. 부록 A·B의 ● 항목이 기준 기기(휴대폰·태블릿, 세로·가로)에서 모두 동작한다.
3. 결함 심각도: 치명=앱 종료·데이터 손실·원본 변경 / 주요=필수(●) 기능 불가 / 경미=표시 오류. QA 보고서에 치명·주요 0건.
4. 5장 비기능 기준을 모두 충족한다.
5. 감수팀 최종 감수를 통과한다.
6. 대표님이 시험용 APK를 써 보고 승인한다.
