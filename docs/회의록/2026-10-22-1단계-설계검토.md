## 2. 결정
| 번호 | 결정 | 근거 |
|---|---|---|
| M-01 | 리플로 문서의 전체 쪽 수는 처음엔 진행률·장 안 쪽으로 표시하고, 계산이 끝나면 쪽 수로 바꾼다 | UX 1, 엔진 S-21 |
| M-02 | 글자 크기·보기 설정은 손을 뗀 뒤 0.3초 후 지금 장부터 다시 조판. 두 손가락 글자 크기 조절은 기본값 '끔' | UX 2, 엔진 제스처 |
| M-03 | 넘김 효과 뒷면은 현재 테마 바탕색으로 섞는다. 넘기는 동안 강조(형광펜·검색·TTS)는 쪽 비트맵에 합성, 정보줄은 고정 | UX 3·4 |
| M-04 | 이북식 보기의 넓은 표는 폭 맞춤 + '표 크게 보기' 창 | UX 5 |
| M-05 | 리플로 스크롤 보기는 위아래 여백 없이 조판해 이어 붙임. 테마는 리플로=CSS, 고정 쪽=셰이더 반전 | UX 6·7 |
| M-06 | HWP 원본은 앞 3쪽 미리 해석. 미준비 쪽은 바탕색 빈 종이 + 진행 표시 | UX 8 |
| M-07 | 고정 레이아웃 EPUB(pre-paginated)은 만화 엔진으로 연다. EPUB DRM(encryption.xml·rights.xml)은 '서점 보호' 안내 | UX 12·14 |
| M-08 | 암호 DOCX는 실험 ②에서 해제 방식 검증, 안 되면 안내 문구로 대체 | UX 13 |
| M-09 | 글꼴: 본문 명조 1종(대표님 선택) + 고딕 1종 번들. 한자는 기기 CJK 글꼴로 대체. 사용자 글꼴은 TTF/OTF만 | UX 15, 엔진 글꼴, P12 |
| M-10 | 대표님께는 arm64 APK 하나만 전달. v7a는 최저 기기 시험용 | UX 16 |
| M-11 | 백업 파일 이름 `ASH백업_YYYY-MM-DD.ashbak`, '합치기'·'모두 바꾸기' 둘 다 지원, '내 글꼴도 넣기' 스위치 | UX 17 |
| M-12 | 칸 탭 대기 시간·위 띠 메뉴 위치는 실험 ③에서 200/250/300ms 비교 후 확정 | 엔진 경미 |
| M-13 | PDF 원본↔이북식 전환은 "대략 같은 위치"로 기대치 명시. 스캔 판정은 첫 3쪽 글자 수, 판정 전 도구줄 4번 칸은 비워 둠 | 엔진 주요 |
| M-14 | N-05: `tools:node="remove"` 쓰지 않음(원인 라이브러리 제거). CI에 aapt2 최종 APK 검사·음성 시험 추가 | P7·P8 |
| M-15 | 라이선스 표기 AGPL-3.0-or-later로 통일. LICENSE·SPDX 머리말, 릴리스마다 source.zip, 고지 화면에 소스 받는 방법 | P5 |
| M-16 | 요구사항서 v0.6.2: N-06 측정 방법, N-10 시간 측정 공통, N-02 solid CBR 예외, F-28 빈 쪽 판정 | P1·P2·P6·P13 |
