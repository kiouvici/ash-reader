# Word 원본(구조 보존) 보기 시각 대조 — 2026-10-23 (배치 4D, 조건 C4)

- 대상: F-30 Word 원본 보기(`DocxPaged`·`RtfPaged` → `PagedComposer` PDF). 기준 = 같은 폴더의 `*.ref.pdf`.
- 방법: 호스트 JVM(x86_64)에서 앱과 같은 Kotlin 코드 + MuPDF 1.28.5(ASH 패치) Java 바인딩으로 PDF를 만들고, `scripts/word-compare/compare.py`로 두 PDF를 60dpi 회색조로 렌더해 쪽마다 비교(쪽 번호끼리 짝지음).
  - SSIM: 가우스 흐림(σ=2px) 뒤 구조 유사도. 1.0 = 같음.
  - 줄 IoU: 잉크를 가로 0.6in·세로 0.06in로 팽창한 '줄 띠'의 겹침 비율(낱자 위치 대신 줄·문단·표 배치).
  - 세로 상관: 행별 잉크 양 분포의 상관계수(줄 높이·간격).
  - 첫 줄 일치: 머리글 아래 첫 본문 줄 앞 8글자가 같은 쪽 수(쪽 나눔 위치).
- 실무 문서(real-03·real-04)는 수치만 적는다(그림·글자 미포함, 파일은 저장소 밖).
