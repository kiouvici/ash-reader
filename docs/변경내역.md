# 변경 내역

## 1.0.0 (첫 정식판)

인터넷 없이 이북·만화·한글·Word 문서를 읽는 안드로이드 리더의 첫 정식판입니다. 휴대폰·태블릿(Android 8.0 이상, 64비트).

### 읽을 수 있는 형식
- 이북: EPUB, MOBI·AZW3(EPUB 로 바꿔 열기), FB2, HTML, TXT(UTF-8·CP949·UTF-16 자동 판별, 인코딩 직접 고르기), CHM
- 문서: PDF(암호 PDF 포함), DjVu, HWP·HWPX, DOCX·DOC·RTF
- 만화: CBZ·CBR·CB7, 그림만 든 PDF(만화로 보기)
- XPS 는 아직 지원하지 않으며 열 때 그렇게 알려 줍니다(D-018).

### 읽기
- **원본 보기**(문서 모양 그대로)와 **eBook 보기**(화면에 맞게 다시 나누기). 한글·Word 는 둘 다 고를 수 있습니다.
- 종이 넘김 효과, 태블릿 가로 화면 두 쪽 펼침, 스크롤 보기·자동 스크롤.
- 글꼴(나눔명조·리디바탕·마루부리·내 글꼴), 글자 크기·줄 간격·여백·문단 간격·정렬·들여쓰기·줄 바꿈.
- 듣기(TTS), 본문 검색, 목차, 책갈피, 형광펜·메모(내보내기), 원본 보기 글자 선택·사전 찾기.
- 밝게·어둡게 테마, 화면 가장자리 밝기 조절.
- 화면을 돌려도 읽던 자리를 지키고(작업 11), 같은 화면이면 몇 번을 다시 열어도 쪽 번호가 같습니다(작업 12).

### 만화
- 웹툰(세로 이어 보기), 펼침 배치, 테두리 자르기, 보정.
- **AI 화질 향상**(Real-CUGAN, 기기 안에서 처리) + 전후 비교. 이북·PDF 속 그림에도 쓸 수 있습니다.

### 서재
- 서재 폴더(여러 폴더·하위 폴더), 형식·폴더·시리즈 묶음, 다음 권 이어 읽기, 최근 책장 줄.
- 한 번만 보기(카카오톡 등 다른 앱에서 연 문서는 서재에 남기지 않음).
- 독서 기록(월별 통계), 즐겨찾기·모음, 백업 내보내기·가져오기.
- 책 정보 찾기(표지·지은이·출판사, **기본 꺼짐**): 국립중앙도서관·카카오 책 검색·구글 북스에 HTTPS 로 제목·권수만 보냅니다. 책 파일·본문·폴더 경로는 보내지 않습니다(D-024).

### 보안·배포
- 인터넷 권한은 책 정보 찾기 한 곳만 쓰며, 그 밖의 위험 권한은 없습니다(자동 검사).
- 정식 서명 키는 대표 승인을 거친 배포 빌드에서만 씁니다(D-027).
- 라이선스 AGPL-3.0-or-later. 릴리스에 APK·소스·서드파티 소스·고지(THIRD_PARTY_NOTICES)를 함께 올립니다.

### 알려진 한계
- Word 원본: 이어지는 구역의 단 수 변경, DOC 탭 맞춤 종류, EMF+ 일부(I-501~503).
- HWP 원본 글자 선택: 세로쓰기·회전 글상자·수식은 고를 수 없음(I-774).
- HWP eBook 보기: 칸이 아주 많은 표는 좁은 화면에서 오른쪽이 넘칠 수 있음(I-783).
- 좁은 휴대폰 화면에서 띄어쓰기가 적은 줄은 낱말 사이가 넓어 보일 수 있음(I-792).
- 32비트 전용 기기에는 설치되지 않음(D-020).
