# 시험 파일 목록

`test-files/public/` 은 저장소에 포함해 CI에서 쓴다. `test-files/private/`(대표님 실무 파일)은 저장소에 올리지 않는다(D-006).

## Word (실험 ②, 문서 엔진 개발자 2 작성 — QA 정식본이 나오면 교체·추가)

| 파일 | 형식(실제) | 내용 | 만든 방법 | 용도 |
|---|---|---|---|---|
| `word-structure.docx` | DOCX | 제목 1·2, 굵게·기울임, 번호 목록 3·글머리 2, 4×4 병합 표(가로·세로 3행·2×2 사각), 중첩 표, PNG 그림 2(인라인), 머리글·바닥글(첫 쪽 다름: first/default), 각주 1, 쪽 나눔 | python-docx 1.2.0 + 각주 XML 직접 주입 | F-30 구조 대조 |
| `word-structure.ref.pdf` | PDF | 위 파일의 기준 출력본(2쪽) | LibreOffice 24.2 `--convert-to pdf` (Word 출력본 아님) | 대조 기준 |
| `word-structure.ref.txt` | 텍스트 | 기준 PDF의 글자(`pdftotext -layout`, 표를 행 순서로 읽음) | poppler pdftotext | 단위 테스트 자동 대조 |
| `word97-structure.doc` | DOC(Word 97-2003, OLE `WordDocument`) | 위 DOCX와 같은 내용 | LibreOffice `--convert-to "doc:MS Word 97"` | F-31 본문·표 텍스트 |
| `word-encrypted-agile.docx` | 암호 OOXML(OLE `EncryptionInfo` 4.4 Agile, AES-256-CBC, SHA-512, spinCount 100000) | `word-structure.docx`를 암호화. **암호 `ash1234`** | msoffcrypto-tool 6.0.0 `OfficeFile.encrypt` | F-34·M-08 |
| `word-corrupt.docx` | DOCX(손상) | `word-structure.docx` 앞 20,000바이트만 남김 | `head -c` | F-35 손상 파일 |
| `rtf-named-as.doc` | RTF | 확장자는 .doc, 내용은 RTF(한글 `\u` 포함) | 직접 작성 | F-05 시그니처 판별 |

부족분(QA 몫): 대용량, 한글 파일명, 떠 있는 그림, EMF 그림, Word로 만든 원본·Word PDF 출력본, Standard(Office 2007) 암호 DOCX.

## 4A 형식 (DjVu·CHM·TXT 인코딩) — 앱 개발 팀 작성, 저작권 없는 직접 만든 내용

| 파일 | 형식(실제) | 내용 | 만든 방법 | 용도 |
|---|---|---|---|---|
| `djvu-sample.djvu` | DjVu(묶음, DJVM) | 2쪽(색 그림), 목차 3줄(한글, 2단), 1쪽 숨은 글자층("Hello DjVu", "숨은 글자") | 합성 PPM → DjVuLibre 3.5.30 `c44`·`djvm -c`·`djvused set-outline/set-txt` | DjVu 열기·목차·표지·F-05 판별 |
| `chm-sample-cp949.chm` | CHM(ITSF v3, 무압축 section 0) | 2장 HTML(CP949, `charset=euc-kr`, `<script>` 포함), HHC 목차 2단, GIF 1 | `scripts/test-files/make_chm.py` | CHM → EPUB 변환·CP949 HTML·스크립트 제거·F-05 판별 |
| `txt-cp949.txt` | TXT(CP949, EUC-KR 에 없는 '똠·뷁' 포함) | 소설 첫머리 3줄 | Python `encode('cp949')` | F-32 자동 판별 |
| `txt-utf16le-bom.txt` | TXT(UTF-16 LE, BOM) | 위와 같은 글 | Python `encode('utf-16-le')` + BOM | F-32 자동 판별 |

MOBI·AZW3 는 공개 시험 파일이 없다(QA 몫: DRM 없는 AZW3·KF8 겸용 MOBI·DRM MOBI 각 1종). 변환 경로는 libmobi 저장소의 시험 표본(sample-cp1252·multimedia·drm-v1/v2)으로 개발 중 확인했다(저장소에 넣지 않음).
